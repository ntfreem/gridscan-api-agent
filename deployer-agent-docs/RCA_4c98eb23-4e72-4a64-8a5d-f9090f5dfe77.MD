## Blast-radius implications
- The user's mental model of a `metadata.source` tag ("platform" vs "custom") does NOT match production data — the field is absent on all 7 discord connected_accounts. Any clearing logic keyed on that field will match nothing.
- Each connected_account carries its own embedded bot credentials matching the global config. Clearing/changing ONLY discord_app_config will leave all 7 accounts still holding the old embedded token — they will not auto-inherit the change.
- All discord connected_accounts + the 6 guild mappings are concentrated under one org (ef775d19...).
